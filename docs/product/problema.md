# Problema y diferenciación

Las promociones bancarias en Argentina varían por día, billetera, banco y
tarjeta, con tope de reintegro mensual compartido y letra chica difícil de
seguir. El usuario paga con el primer medio disponible y pierde plata sin
darse cuenta — el problema no es la falta de información, es la decisión.

Vuelto no es un listado de promociones: recomienda **qué pagar en una
compra concreta** y controla **cuánto tope de reintegro queda**.

> Regla de oro: si se puede describir como "mostrar promociones", no es
> este producto.
