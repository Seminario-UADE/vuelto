Joaquín · Uso de IA
Límites y trazabilidad

Cuatro garantías, y cada sesión queda registrada

1

Sin LLM en el motor

La recomendación sale de código con tests.

2

Revisión humana

Ninguna promo se publica sin que una persona la apruebe.

3

Key en el servidor

La API key de Gemini nunca viaja al celular.

4

Tickets sin imagen

Se descartan tras el envío; solo queda el texto.

Bitácora de prompts

Evidencia para la cátedra

Cada entrada: fecha, herramienta, objetivo, prompts principales y resultado. Hoy hay 5 sesiones registradas.
